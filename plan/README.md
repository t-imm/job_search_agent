# plan

This directory contains a camel python code to generate a plan for the job search agent.

## Directory Layout

- `camel_planning.py`: contains the logic to generate a plan using camel. 
- `camel_test.ipynb`: a Jupyter notebook to test the camel planning code using `test_prompt.txt`.
- `camel_planning.ipynb`: a Jupyter notebook to generate a plan using camel with `plan_prompt.txt`.
- `output.txt`: contains the raw communication output from camel when generating the plan.
- `output.md`: contains the formatted output from camel when generating the plan.
- `personal_reflection.md`: contains the personal reflection on the process of generating a plan using camel.
